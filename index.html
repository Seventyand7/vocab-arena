LIBRARY

GEMINI API KEY

翻譯功能需要你自己的 Gemini API key。到 Google AI Studio 建立一組後貼在下面。

金鑰會存進你自己的 Firestore 文件 users/<你的 uid>/settings/geminiKey，受 Security Rules 保護，只有你自己讀得到，不會寫進程式碼也不會進 git。

模型

模型會改版、退役，寫死的名稱早晚會失效。按「偵測可用模型」會直接問 API 你的金鑰現在能用哪些，清單由便宜到貴排序。

ACCOUNT

你的 UID（設定 Security Rules 用）

排程規則

  • 建立後第 1 / 3 / 7 天必定各出現一次（不論熟悉度）。
  • 熟悉度 0–5 對應複習間隔 1 / 2 / 4 / 7 / 14 / 30 天。
  • 單字卡「記得」＋1、「不熟」歸零；配對成功＋1、配對失敗兩張各 −2。
  • 候選不足時，以熟悉度越低權重越高的加權隨機補足。
